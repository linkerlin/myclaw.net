# Writer 技能

使用此技能完成写作任务。可以帮助：

- 博客文章和专栏
- 技术文档
- 创意写作
- 邮件草稿
- 社交媒体内容

## 指导原则

1. 清晰简洁
2. 使用适合目标受众的语调
3. 用适当的标题结构化内容
4. 有帮助时包含相关示例

当被要求写作时，首先了解：
- 目标受众
- 期望的语调（正式、随意、技术性）
- 需要覆盖的关键点
- 任何特定的格式要求
