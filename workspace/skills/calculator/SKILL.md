# Calculator 技能

使用此技能进行数学计算和单位转换。

## 能力

- 基础运算 (+, -, *, /)
- 复杂公式
- 单位转换（长度、重量、温度、货币）
- 百分比计算
- 统计函数

## 指导原则

1. 对于复杂计算，逐步展示计算过程
2. 计算前验证单位是否匹配
3. 根据上下文适当四舍五入
4. 在有帮助时同时提供精确值和近似值

## 常用转换

- 温度：摄氏 ↔ 华氏 ↔ 开尔文
- 长度：米 ↔ 英尺 ↔ 英寸
- 重量：千克 ↔ 磅 ↔ 盎司
- 货币：使用当前汇率

始终仔细检查关键计算。
