# Web Search 技能

当用户需要在网络上搜索信息时使用此技能。

## 使用场景

- 用户询问时事或新闻
- 用户需要你可能没有的事实信息
- 用户想比较产品或服务
- 用户询问特定网站或在线资源

## 指导原则

1. 构建有效的搜索查询
2. 简洁总结发现的内容
3. 相关时包含来源 URL
4. 如果信息时效性强，注明日期

## 可用工具

- 网页搜索 (Brave API)
- URL 抓取特定页面

尽可能从多个来源验证信息。
